# 🚀 SUI Comandos Esenciales

> **Guía completa y didáctica para principiantes en la blockchain SUI**

## 📖 Sobre el Proyecto

Este repositorio fue creado con el objetivo de facilitar el aprendizaje de desarrollo en la **blockchain SUI** a través de una documentación clara, organizada y práctica.

Ideal para:
- 🎓 **Estudiantes** comenzando en SUI
- 👨‍💻 **Desarrolladores** migrando a SUI
- 👩‍🏫 **Educadores** que necesitan material didáctico
- 🚀 **Entusiastas** de la tecnología blockchain

## ✨ Características

- **📚 Documentación completa** - Todos los comandos esenciales explicados
- **🛠️ Setup automático** - Script para configurar ambiente DevNet
- **💡 Ejemplos prácticos** - Contratos Move listos para probar
- **🔍 Referencia rápida** - Comandos más usados organizados
- **❗ Troubleshooting** - Soluciones para problemas comunes
- **🌐 Recursos externos** - Enlaces a comunidad y documentación oficial

## 🎯 Contenido

### Comandos Cubiertos
```bash
sui client faucet          # Solicitar tokens de prueba
sui client gas             # Verificar gas disponible
sui client balance         # Consultar saldo
sui client active-address  # Ver dirección activa
sui move new              # Crear proyecto Move
sui client new-env        # Configurar ambiente
sui client envs           # Listar ambientes
sui client switch         # Cambiar ambiente
```

### Ejemplos Incluidos
- 🌟 Hello World
- 🔢 Contador Simple
- 🪙 Token Personalizado
- 🖼️ NFT Collection
- 🛒 Marketplace Básico

## 🚀 Cómo Usar

1. **Clona el repositorio**
2. **Ejecuta el setup**: `./setup.sh`
3. **Sigue los tutoriales** en la carpeta `docs/`
4. **Prueba los ejemplos** en la carpeta `exemplos/`
